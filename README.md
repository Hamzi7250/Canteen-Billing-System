# Campus Canteen Billing System

A beginner-friendly billing system built using Python basics.

## Features
- Four menu items with prices in PKR
- Multiple orders until checkout
- Quantity-based billing
- 10% discount on bills of PKR 1,000 or more
- Total quantity, subtotal, discount, and final bill

## Menu
1. Burger - PKR 350
2. Pizza Slice - PKR 250
3. Sandwich - PKR 200
4. Cold Drink - PKR 100

Enter `0` to checkout.

## Requirements
- Python 3

## How to Run
1. Open the project folder in VS Code.
2. Open the terminal.
3. Run:

   ```bash
   python canteen.py
   ```

## Concepts Used
Variables, `print()`, `input()`, operators, `if/elif/else`, `while`, `break`, and `continue`.
